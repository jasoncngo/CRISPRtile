## CRISPRtile
CRISPRtile is available as a google colab at https://colab.research.google.com/drive/14fvBFYtHNU73_JlbyRMZYwv8L84HKisk?usp=sharing

The input file is provided in the supplementary material of the paper and will take about a day to run. The google colab contains a working notebook. The notebook provided in this repository contains the dependencies and instructions to run.
